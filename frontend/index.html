Hướng dẫn Đấu nối Số WhatsApp Thực tế (Meta Cloud API)

  1. Mở đường hầm HTTPS cục bộ trỏ vào cổng 8080: ngrok http 8080 hoặc cloudflared tunnel --url http://127.0.0.1:8080.
  2. Trong Meta App Dashboard → WhatsApp → Configuration, nhập Callback URL: https://<your-tunnel>/api/whatsapp/webhook.
  3. Nhập Verify Token khớp với biến WHATSAPP_VERIFY_TOKEN trong tệp .env.
  4. Tùy chọn bật WHATSAPP_APP_SECRET để hệ thống tự động xác thực chữ ký X-Hub-Signature-256 chống giả mạo gói tin.
